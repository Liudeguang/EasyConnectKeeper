# EasyConnectKeeper

**EasyConnectKeeper** 是一款专为 **EasyConnect VPN** 客户端定制的轻量级自动联通与连接保持（保活）辅助工具。

旨在解决在使用 EasyConnect VPN 过程中，因长时间无数据交互导致连接被网关强制自动断开、或频繁需要重新登录的问题。

---

## 🚀 功能特点

- **🛡️ 状态实时监测**：自动检测 EasyConnect 客户端进程的运行状态以及内网连通性，提供直观的颜色标识状态反馈。
- **🔌 TCP 自动保活**：基于底层 TCP 连接周期性发送心跳探测包（Keep-Alive），以非侵入方式维持隧道活跃状态。
- **📥 系统托盘运行**：支持最小化至系统托盘静默运行，避免占用您的任务栏和桌面空间。
- **📝 运行日志记录**：实时记录保活检测状况，自动在运行目录创建本地日志文件（如 `logs/2026-05-25.log`），方便诊断。

---

## 🛠️ 工作原理

本程序开启“保持连接”后，会利用 `TcpClient` 在后台建立一个持久化连接，并使用 Windows 特有的 **TcpKeepAlive** 参数：
1. **探测周期**：默认以您设定的周期（例如每 10 分钟）进行一次内网心跳探测。
2. **保活重试**：当检测到连接可能空闲时，底层 TCP 套接字会持续发送极轻量的保活探测包（Keep-Alive Probe），向 VPN 网关伪装活动状态。
3. **安全非侵入**：本软件不改变任何系统级网络配置，亦不干扰 EasyConnect 本身的正常工作。

## 📖 使用指南

### 第一步：手动建立 VPN 连接
在使用本程序前，请确保您已经启动 **EasyConnect** 官方客户端并正常登录，确认内网网络已经可以正常访问。

### 第二步：启动 EasyConnectKeeper
运行 `EasyConnectKeeper.exe`（如果需要编译，可直接使用 Visual Studio 打开并构建）。

### 第三步：配置探测参数
- **主机 (Host)**：请输入您内网中可稳定访问的服务器或网关 IP（如 `10.0.0.1` 或是您的内网数据库、Web 服务器 IP 等）。
- **端口 (Port)**：对应服务器开启的开放端口（如 `80`、`3306` 等）。
- **周期 (分钟)**：发送心跳探测的频率，建议保持默认值（如 10 分钟）。

### 第四步：开启保持连接
点击界面上的 **[开启保持连接]** 按钮。
- 程序状态将转为**保持连接活跃中**（界面呈现紫色状态标识）。
- 此时您可以安心工作，VPN 隧道将始终保持联通。点击最小化即可静默运行于系统托盘。

## ❓ 常见问题 (FAQ)

**Q: 点击“停止保持”会断开 VPN 吗？**  
A: 不会。它只会停止本辅助程序的心跳发送，您原本的 EasyConnect 客户端连接将完好无损。

**Q: 为什么状态显示“EasyConnect 未运行”？**  
A: 请确认您是否已经启动并成功登录了官方的 EasyConnect 客户端。

**Q: 日志文件存储在什么地方？**  
A: 程序会在其运行目录下的 `logs` 文件夹内生成每日日志。
